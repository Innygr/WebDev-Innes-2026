Combination Lock

An embedded combination-lock prototype with physical controls and an electronic interface.

← Back to project index

Project overview

The project is a combination lock built around a XIAO ESP32-S3. A HW-504 joystick is used for input, a 128×64 OLED displays the interface, and servos operate the locking mechanism. A mini speaker provides audio feedback.

Hardware

  • XIAO ESP32-S3 microcontroller
  • HW-504 joystick module
  • 128×64 OLED display
  • Two servo motors
  • Mini speaker
  • Breadboard, wiring, and 3D-printed components
