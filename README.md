# WebDev Innes — 2026

A student web-development portfolio containing HTML assignments, robotics and embedded-systems projects, interactive demos, and project evidence.

## Visit the site

**[Open the live portfolio](https://innygr.github.io/WebDev-Innes-2026/)**

## What's here?

- **Course assignments** — introductory HTML, tables, lists, and forms.
- **Robotics hub** — interactive 3D crystal scene and project navigation.
- **Combination lock** — final project overview, system diagram, and browser-based 3D prototype.
- **Project evidence** — media from embedded-systems work, including BLE, LoRa, on-device vision, and a web server.
- **WebMCU AI** — notes and instructions for an on-device vision-model activity.
